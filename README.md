# 🚀 Astra Mining

Astra Mining is a space-themed **mining / idle-game simulation interface** designed with a mobile-first experience and Telegram Mini App compatibility in mind.

The current GitHub version is **fully frontend-based**. It does not include real payments, blockchain transactions, investments, or a centralized backend.

> **⚠️ Simulation Only:** This project is intended for educational, prototyping, and UI demonstration purposes. All balances, tokens, power values, rewards, and payment actions shown in the application are simulated.

---

## ✦ Features

### 🌌 Cosmic Dashboard

* Space-themed dark interface
* Dynamic star field
* Nebula and holographic HUD effects
* Animated agent core with orbital visuals
* Responsive mobile-first design
* Suitable for desktop and Telegram WebApp environments

### ⚡ Mining Simulation

* 24-hour mining cycles
* Timestamp-based production system
* Progress preserved when the page is closed
* Token production based on Power
* Ability to restart the mining cycle when it completes

### ◈ Economy System

The simulation contains three primary values:

| Value     | Description                       |
| --------- | --------------------------------- |
| **Power** | Represents mining capacity        |
| **Token** | Virtual asset generated by mining |
| **USD**   | Simulated account balance         |

The economy also includes:

* Token selling simulation
* Power upgrade system
* First upgrade bonus
* Daily token production
* Rank progression
* Transaction history

### 🤖 Agent System

Players can unlock different Astra agents by increasing their Power level.

```text
NOVA
  ↓
PULSAR
  ↓
QUASAR
  ↓
NEBULA
```

Agents are visual upgrades and do not affect mining production speed.

### 🏆 Rank System

Rank progression is based on Power:

```text
Planet
   ↓
Asteroid
   ↓
Star
   ↓
System
   ↓
Galaxy
   ↓
Universe
```

### 🎯 Task System

The task system contains several categories:

* Referral tasks
* Social task simulations
* Daily check-in
* Balance deposit tasks
* Reinvestment tasks
* Reward tracking

Completed tasks reward the player with simulated Power.

### 🔥 Daily Streak

The daily check-in system includes:

* Daily claim
* Streak tracking
* Consecutive-day progression
* Power rewards
* Persistent local storage

The streak continues when the previous day was completed. Longer gaps reset the streak.

### ⚡ Mini Game

Astra Mining includes a small 10-second reaction game.

The player:

1. Starts the game
2. Clicks the energy cores appearing on the screen
3. Earns points
4. Receives a simulated Token reward based on the score

The game also has a daily play limit.

### 👥 Referral Simulation

The referral system is designed around three levels:

```text
Level 1 → 15%
Level 2 → 7%
Level 3 → 2%
```

For development and demonstration purposes, virtual referral users can also be generated.

The referral system includes:

* Referral count
* Referral list
* Level filtering
* Referral rewards
* Referral tasks
* Demo referral generation

### 🌐 Internationalization

The application currently supports:

* 🇹🇷 Turkish
* 🇺🇸 English

Most interface text is managed through centralized translation dictionaries, making additional languages easy to add.

### 💾 Local Persistence

The application stores simulation data in the browser using:

```text
localStorage
```

Stored data includes:

* USD balance
* Token balance
* Power
* Rank progression
* Mining cycle
* Daily streak
* Referrals
* Completed tasks
* Agent selection
* Transactions
* Mini-game usage

This allows the simulation to persist after refreshing, closing, and reopening the page.

# 📱 Telegram Mini App Compatibility

Astra Mining is designed to work with the Telegram WebApp SDK.

The application can also run normally as a standalone web page without Telegram.

When Telegram WebApp is available, the application can use basic WebApp functionality such as:

* `Telegram.WebApp.ready()`
* `Telegram.WebApp.expand()`
* Telegram theme integration

Telegram is **not required** for the current GitHub version to function.

> The current build does not require a Telegram bot, backend, or server-side account system.

# 🔐 Data & Security

This repository is intended for **demo and simulation purposes**.

All application data is stored locally:

```text
Browser
└── localStorage
```

Therefore:

* LocalStorage values can be modified by the user.
* Token and Power values are not trusted financial data.
* Transaction records are simulation records only.
* Referral data is not server-verified.
* The Payment section does not perform real transactions.
* No blockchain connection is included.

A production implementation would require server-side systems such as:

```text
Telegram Authentication
Server-side State
Database
Transaction Ledger
Rate Limiting
Referral Validation
Task Verification
Payment Provider
Blockchain Integration
Fraud Prevention
Server-side Economy
```
